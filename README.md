# Stressie website

The live marketing site at https://www.stressieapp.com: the companies home page, the wellness partners page, Manifesto, Contact, Privacy, Terms, Impact (Te Vemos), and a beta waitlist for people and teams.

Plain HTML, CSS and JS served by GitHub Pages from `main`. Pushing to `main` publishes.

- `CLAUDE.md`: how to edit and publish, and the rules
- `DESIGN.md`: the design system (colours, type, components, motion, voice)
- `python tools/check_links.py`: run before every push
